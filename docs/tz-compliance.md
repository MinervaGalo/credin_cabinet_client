## Расхождения и пробелы

| Что | Как сейчас | Что нужно для полного соответствия |
|---|---|---|
| OCR (раздел 8) | Текст извлекается из PDF и TXT, сканы и фото не читаются | Подключить OCR, например Tesseract, перед разбором |
| Отдельный AI Service (раздел 3, необязательный) | ИИ встроен в `core`, модель в контейнере `ollama` | Вынести `ai.py` в отдельный сервис |
| Миграции БД (раздел 10) | Таблицы создаются командой `create_all` | Добавить Alembic |
| CRUD компаний и продуктов (раздел 10) | Продукты и поиск компании доступны только на чтение | Добавить методы создания и изменения для аналитика |
| CI/CD (раздел 10) | Нет | Добавить workflow с тестами и сборкой образов |
| AI при `docker compose up --build` (раздел 9) | Контейнер `ollama` запускается только с профилем `ai`, модель скачивается вручную | Включить профиль по умолчанию и загружать модель при старте |
| Авторизация | Токены самописные, регистрации нет | Использовать готовую библиотеку JWT и добавить регистрацию |
| Базовый балл скоринга | В ТЗ пример с 100 баллами, в системе 400 | Параметр `SCORE_BASE` в `config.py`, пример из ТЗ считался иллюстративным |

## Не проверено

- Запуск `docker compose up --build` на реальном Docker: в среде разработки не было Docker-демона, проверен только синтаксис файла командой `docker compose config`.
- Работа на PostgreSQL: тесты идут на SQLite. Код не использует специфику СУБД, но первый запуск стоит сделать до сдачи.
