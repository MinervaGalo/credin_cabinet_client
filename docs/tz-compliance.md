## Расхождения и пробелы

| Что | Как сейчас | Что нужно для полного соответствия |

| CRUD компаний и продуктов (раздел 10) | Продукты и поиск компании доступны только на чтение | Добавить методы создания и изменения для аналитика |

## Закрыто по замечаниям

| Замечание | Что сделано |
|---|---|
| OCR не подключён | Tesseract в образе `core`: фото (PNG, JPG) и сканы PDF распознаются перед разбором отчётности. Если Tesseract недоступен, метод разбора возвращает понятную ошибку |
| Самописные токены, нет регистрации | JWT на python-jose, пароли на passlib (PBKDF2), метод `POST /api/auth/register` |
| Нет миграций | Alembic, базовая миграция, применяется при старте. Тест проверяет, что миграция совпадает с моделями |
| Нет CI/CD | GitHub Actions: ruff и black, тесты на SQLite, тесты на PostgreSQL, сборка Docker-образов |
| Тесты только на SQLite | Тесты запускаются и на PostgreSQL (переменная `TEST_DATABASE_URL`), все проходят |

## Не проверено

- Сборка образа `core` с установкой Tesseract через apt: проверена только конфигурация, образ собирается впервые на вашем компьютере.
- Запуск workflow в GitHub Actions: файл проверен как YAML, но сам workflow выполнится только после отправки в репозиторий.
- Распознавание реальных сканов: проверено на сгенерированных изображениях с чистым текстом, качество на фото документов зависит от съёмки.
